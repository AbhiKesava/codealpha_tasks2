# Phishing Awareness Training

A cybersecurity awareness project designed to educate users about phishing attacks, fake websites, and social engineering techniques.

## Project Objectives

- Understand phishing attacks
- Identify phishing emails
- Detect fake websites
- Learn social engineering tactics
- Follow cybersecurity best practices
- Improve online safety awareness

## Topics Covered

- Introduction to Phishing
- Types of Phishing Attacks
- Recognizing Fake Emails
- Detecting Fake Websites
- Social Engineering Attacks
- Real-World Phishing Examples
- Prevention Techniques
- Interactive Quiz

## Technologies Used

- Microsoft PowerPoint
- Cybersecurity Awareness Concepts
- Visual Learning Materials
